のみ記録（iPhone用PWA）

1. このフォルダ内のファイルをまとめてHTTPS対応の静的Webホスティング（GitHub Pages、Netlifyなど）へ公開します。
2. iPhoneのSafariで公開URLを開き、共有 → ホーム画面に追加 を選択します。
3. ホーム画面のアイコンから起動すると、記録が端末内に保存されます。
4. 設定 → CSV書き出し から定期的にバックアップしてください。

注意：ファイルをiPhoneにコピーするだけではPWAとしてのオフライン機能は利用できません。HTTPSで公開後、一度オンラインで開いてください。ブラウザデータを消去すると記録が失われることがあります。
